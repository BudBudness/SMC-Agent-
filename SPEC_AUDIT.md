# Intelligence-system specification

## Core objective
Investigate and explain market structure rather than execute trades.

## Required pipeline
DATA → NORMALIZATION → MULTI-TIMEFRAME STATE → STRUCTURE → LIQUIDITY → SMC EVENTS → MACRO CONTEXT → HISTORICAL ANALOGUES → HYPOTHESES → EVIDENCE → INTELLIGENCE REPORT.

## Required distinctions
- observation ≠ interpretation
- interpretation ≠ hypothesis
- historical frequency ≠ prediction
- scenario ≠ recommendation
- confidence reflects evidence coverage, not certainty

## Current baseline
- Multi-timeframe hierarchy
- Weekly structural authority
- Liquidity mapping / sweep detection
- CHoCH / BOS
- Displacement
- FVG / OB
- Premium / discount
- 4H AMD hook
- Macro event context interface
- Historical analogue interface
- Hypothesis/report structures
- Causal backtest foundation
- OOS / walk-forward foundation
- Research dashboard

## Removed by design
- Live execution
- Paper trading
- Broker adapters
- Position management
- Execution risk gates

## Remaining intelligence work
- Full protected-swing and liquidity clustering research
- Rigorous inducement model
- Event sequencing / causal graph
- Cross-timeframe contradiction engine
- Historical analogue similarity scoring
- Regime-conditioned statistics
- Macro-to-price reaction analysis
- Event-study framework
- Narrative generation from evidence
- Research-grade dataset validation
- Full audit trail for every inference
